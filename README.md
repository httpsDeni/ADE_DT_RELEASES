# ADE DT — Downloads

Instaladores oficiais do **ADE DT** (Agent Development Environment Desktop Tool), o painel para comandar vários agentes de IA em paralelo.

**Baixe a versão mais recente na aba [Releases](../../releases/latest).**

| Sistema | Arquivo |
|---------|---------|
| Windows | `ADE-DT-Setup-<versão>.exe` |
| macOS (Apple Silicon, M1 ou mais novo) | `ADE-DT-<versão>-arm64.dmg` |
| macOS (Intel) | `ADE-DT-<versão>.dmg` |
| Linux (qualquer distro) | `ADE-DT-<versão>.AppImage` |
| Linux (Debian/Ubuntu) | `ade-dt_<versão>_amd64.deb` |

Este repositório contém apenas os instaladores publicados como releases. Não há código-fonte aqui.

## Aviso na instalação

O app ainda não tem assinatura digital paga, então o Windows (SmartScreen) ou o macOS (Gatekeeper) pode mostrar um alerta:

- **Windows:** clique em **Mais informações → Executar assim mesmo**.
- **macOS:** clique com o botão direito no app e escolha **Abrir**.
